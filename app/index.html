Mathematics & Methodology

Every displayed score should be traceable to a definition, calibration set, and measured observation. Equations below describe the proposed method—not validated safety guarantees.

1 · Calibrate a token-level risk score

Let p_t ∈ [0,1] be a detector score at token position t. Estimate the mean score on held-safe calibration examples, μₕ, and on known-leak calibration examples, μₗ. Define Δ = μₗ − μₕ. If Δ ≤ 0 or is very small, the detector is not separating the calibration classes reliably and this normalization should be rejected.

r_t = clip((p_t − μₕ) / Δ, 0, 1)

Here clip(x,0,1)=min(1,max(0,x)). This maps scores relative to the calibration gap; it is not automatically a calibrated probability of leakage.

2 · Represent detector disagreement

Suppose K detectors or ensemble members return scores pₜ⁽¹⁾,…,pₜ⁽ᴷ⁾. One possible disagreement statistic is the population standard deviation:

σₜ = √[(1/K) Σₖ (pₜ⁽ᵏ⁾ − p̄ₜ)²]

p̄ₜ is the mean detector score. If the current prototype receives σ directly from a dataset, that σ is an input—not a disagreement estimate computed by this page.

3 · Uncertainty-weighted intervention

wₜ = 1 / (1 + λ αw σₜ)
aₜ = aₘₐₓ rₜ wₜ

λ ≥ 0 controls how strongly disagreement attenuates the intervention; αw ≥ 0 scales disagreement; aₘₐₓ is the maximum intervention magnitude. For nonnegative inputs, wₜ ∈ (0,1] and 0 ≤ aₜ ≤ aₘₐₓ. High disagreement reduces steering; it does not prove that the model is safe. An implementation may instead abstain or escalate when uncertainty is high.

4 · What steering means in representation space

If an activation vector is hₜ ∈ ℝᵈ and a validated intervention direction is d ∈ ℝᵈ, a simple candidate update is (d points toward the leak-prone side, so subtracting moves the state away from it):

h′ₜ = hₜ − aₜ d

The direction, layer, sign, scaling, and normalization must be established experimentally. The dashboard does not currently perform this activation edit.

5 · Evaluation metrics

Leakage rate L / N L = trials with a pre-defined leak; N = evaluated trials.
False-positive rate FP / (FP + TN) Among truly safe evaluated cases.
Utility retention Uguard / Ubase Use a fixed benign-task set and the same scoring rule.
Detection lead time tₗₑₐₖ − tₐₗₑᵣₜ Positive values mean the alert preceded the leak.

Report numerators, denominators, uncertainty intervals, model/version, prompt set, decoding settings, and exclusions. If no leaks occur in a small sample, do not claim a zero underlying risk.

6 · Pareto frontier

For each configuration i, plot (leak_rateᵢ, utility_lossᵢ). Configuration i is dominated if another configuration is no worse on both metrics and strictly better on at least one. The Pareto frontier contains non-dominated configurations; it does not identify a universally best choice.

Scientific limitation: this prototype's existing replay and frontier inputs are synthetic. The original UARD reward-discounting theorem does not automatically apply to activation steering. Any claim about safety improvement requires real, matched, held-out evaluations.

How the intended architecture works

Browser → authenticated HTTPS API → cloud worker/GPU → versioned experiment records → dashboard. The cloud runner should enforce a model allowlist, rate limits, timeouts, and explicit consent. Keep provider keys on the server, never in this HTML file.

Deployment checklist

1. Deploy the provided cloud_runner scaffold to a GPU-capable host.
2. Configure authentication, CORS, resource limits, and an allowed-model list.
3. Implement model-specific activation hooks before claiming representation-drift measurements.
4. Return raw trial counts, model revision, decoding parameters, and provenance with every result.
